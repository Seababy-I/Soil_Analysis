## 1. Crops-NPK Dataset

### Dataset Description
The Crops-NPK dataset contains 20,000 records representing agricultural and crop-growing conditions.

### Main Features
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH Value
- Rainfall
- Crop
- Soil Type
- Variety

### Usage
The dataset may be used for:
- Academic and educational purposes
- Data analysis and research
- Machine learning model development
- Soil and crop recommendation experiments

## 2. Soil Image Dataset

### Dataset Description
The soil image dataset contains images belonging to seven soil classes:
- Alluvial Soil
- Arid Soil
- Black Soil
- Laterite Soil
- Mountain Soil
- Red Soil
- Yellow Soil

### Usage
The dataset is used in this project for:
- Soil image classification
- Image preprocessing
- Exploratory data analysis
- Machine learning and deep learning experiments

### License Considerations
The original dataset source and its applicable license/usage terms should be followed.

## 3. Project Usage
The datasets are being used for the development of an academic project titled:
**AI-Powered Soil Analytics System for Nutrient Assessment and Intelligent Crop Advisory**
